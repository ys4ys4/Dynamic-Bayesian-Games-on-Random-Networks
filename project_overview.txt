# Project Overview: Dynamic Bayesian Learning on Networks

## 1. Core Research Objective
This project studies how network structure affects information aggregation in Bayesian social-learning models. It combines sequential-learning experiments inspired by Acemoglu et al. (2011) with repeated-interaction experiments inspired by Gale and Kariv (2003).

The computational objective is to reproduce relevant theoretical phenomena, compare learning outcomes across network topologies, and use simulation evidence to explore new conjectures. The longer-term research output is a rigorous academic report combining formal setups, theoretical results, and empirical simulation results.

## 2. Mathematical Framework & Game Mechanics
*   **State Space:** True state $\theta \in \{0, 1\}$, with prior $\mathbb{P}(\theta=0) = \mathbb{P}(\theta=1) = 1/2$.
*   **Players:** A finite simulated population of $N$ agents, representing an initial segment of an infinite-agent model where appropriate.
*   **Actions:** Current focus is a binary choice $x_n \in \{0, 1\}$. Future parameter sweeps may test extending the action space to a ternary "hesitation" choice $\{0, 0.5, 1\}$.
*   **Signals & Beliefs:** Agent $n$ receives private signal $s_n \sim \mathbb{F}_\theta$. Measures $\mathbb{F}_0$ and $\mathbb{F}_1$ are mutually absolutely continuous to ensure no signal is fully revealing ($L(s) \in (0, \infty)$ almost surely). 
    **Computer Simulation Signal Structures:**
    *   *Bounded beliefs:* Symmetric Bernoulli distribution with fixed accuracy $q \in (0.5, 1)$.
    *   *Unbounded beliefs:* Gaussian distributions $\mathbb{F}_0 = \mathcal{N}(1, 1)$ and $\mathbb{F}_1 = \mathcal{N}(-1, 1)$.
*   **Updating Rules:** 
    *   *Perfect Bayesian Updating (PBU):* Used for strictly nested topologies (Complete graphs) and Markovian chains (Immediate Predecessor graphs).
    *   *Naïve Bayesian (LLR Summation):* Used as a boundedly rational heuristic to avoid NP-hard complexity on general DAGs, though it introduces correlation neglect ("phantom certainty").
    *   *Monte Carlo Belief Estimator:* A weighted hypothetical-world approximation used for stochastic ER and bounded-sample sequential graphs.

## 3. Network Topologies
Agents observe a neighborhood $B(n)$ governed by probability distribution $\mathbb{Q}_n$. Modeled as Directed Acyclic Graphs (DAGs):
*   **Non-Expanding Observations (NEO):** A "royal family" graph where the first $k$ agents are excessively influential, allowing information cascades.
*   **Expanding / Stochastic:** Erdős-Rényi / Gilbert $G(N,p)$ where agents see predecessors with probability $p$. 
*   **Deterministic:** Complete graph (sees everyone), Immediate Predecessor (sees $n-1$ only).
*   **Bounded Sample:** Each agent observes a fixed-size random sample of predecessors.
*   **Repeated-learning graphs:** Complete-connected, connected-star, and dictator-star networks.

Uniform attachment, Barabási-Albert, and stochastic block model graphs are possible future extensions but are not currently exposed by the graph generator API.

## 4. Standard Notation Guide
*   $N$: Total number of agents/nodes in simulation.
*   $\theta$: True state of the world.
*   $x_n$: Action taken by agent $n$.
*   $s_n$: Private signal of agent $n$.
*   $B(n), \mathbb{Q}_n$: Realised neighborhood and its probability distribution.
*   $q$: Signal accuracy for bounded distributions (default 0.8).
*   $k$: Number of excessively influential agents.

## 5. Tech Stack & Code Architecture
*   **Stack:** Python, NetworkX (graphs), NumPy (vectorisation/math), SciPy (Gaussian CDFs), Pandas (data logging). Version control via Git/GitHub.
*   **Game engines:** `SequentialGame` manages one-pass play and `RepeatedGame` manages multi-round play; both track actions, accuracy, and convergence metrics.
*   **Belief engines:** `SequentialBeliefEngine` and `RepeatedBeliefEngine` separate posterior calculations from game mechanics. Exact fast paths are used for supported structured graphs, while Monte Carlo estimation is used where exact marginalisation is expensive.
*   **Reproducibility:** A single NumPy random generator is threaded through graph generation and gameplay when a seed is supplied.
*   **Numerical stability:** Tie-breaking and likelihood calculations use floating-point safeguards, including `np.isclose` and clipped probabilities where needed.

## 6. Current Project Status
*   **Implemented:** Sequential simulations for NEO, ER, complete, immediate-predecessor, and bounded-sample graphs.
*   **Implemented:** Exact structured belief updates for complete and immediate-predecessor sequential graphs.
*   **Implemented:** Monte Carlo social-belief approximation for ER and bounded-sample sequential graphs.
*   **Implemented:** Repeated simulations for complete-connected, connected-star, and dictator-star networks with unbounded Gaussian signals, including exact belief logic for the supported topologies.
*   **Available entry points:** The `LS_*.py` modules run the configured large sequential experiments; `run_sim` is the reusable API for smaller sequential or repeated runs.
*   **Next steps:** Compare sequential and repeated outcomes under shared network structures, expand parameter sweeps, and investigate the speed-versus-accuracy trade-off across topologies.
